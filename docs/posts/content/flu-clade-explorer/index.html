Influenza Clade Explorer

An Interactive Tool for Visualizing Nextstrain Seasonal Influenza Clade Nomenclature

influenza
tutorial
Author

Elgin Akin

Published

August 3, 2026

Keeping up with influenza clade nomenclature has always been a challenge. As seasonal influenza viruses evolve, new clades emerge and are designated. Recently, Neher…Barr, 2026 published a nomeclature structure for Influenza clade names which follows the previous “subclade designations” within the Nextclade datasets (if you were following those). This updated nomenclature assigns clades based on both size (observed frequency) and phylogenetic structure accounting for several important attributes of influenza (divergence, relvant HA epitopes, etc.) Read the paper for the method itself.

Staying synchronized with the latest definitions is critical for fruitful conversations

However, Viewing a networked structure for Influenza Clades. - This has been done for SARS-CoV-2 through efforts such as CoVariants, however a simplified tool to view a network structure outlining the most up-to-date Influenza Clades, their ancestry, and clade-defining substituttions is lacking.

The Influenza Clade Explorer was created to solve this problem. Rather than bundling static data that quickly becomes outdated, the tool fetches clade definitions directly from the official Nextstrain nomenclature repositories every time it loads. This means users always see the most current hierarchies, mutations, and aliases without needing to download updates or check version numbers.

The benefits of this live-data approach extend beyond convenience. When a new clade is officially designated—whether due to an emerging variant or a nomenclature revision—it appears in the Explorer immediately. Researchers can trust that their analyses are based on the same definitions used by the global surveillance community. And because the tool visualizes the full hierarchy interactively, understanding the relationships between clades becomes intuitive rather than requiring mental reconstruction from tabular data.

Whether you’re selecting vaccine candidates, building bioinformatics pipelines, or simply trying to understand where a particular strain fits in the evolutionary tree, the Influenza Clade Explorer provides a fast, reliable, and always-current window into seasonal influenza nomenclature.

Overview

The Influenza Clade Explorer is a dynamic, interactive web application designed to help researchers, public health professionals, and bioinformaticians navigate the complex hierarchical relationships of seasonal influenza virus clades.

The Problem

Influenza viruses evolve rapidly, and tracking the emergence and spread of new clades is essential for vaccine strain selection, epidemiological surveillance, and evolutionary analysis. However, clade nomenclature systems are inherently complex:

  • Hierarchical relationships between parent and child clades can be difficult to visualize
  • Defining mutations that distinguish clades are scattered across multiple data files
  • Nomenclature updates occur frequently as new variants emerge
  • Alias systems add another layer of complexity to clade naming

Traditional approaches—manually parsing TSV files or consulting static documentation—are time-consuming and prone to falling out of sync with the latest definitions.

Intended Audience

This tool is designed for:

  • Surveillance scientists tracking circulating influenza strains
  • Vaccine researchers analyzing candidate strain relationships
  • Bioinformaticians building pipelines that require current clade definitions
  • Public health officials communicating about influenza evolution
  • Students and educators learning about influenza phylogenetics

Common Use Cases

  • Exploring the evolutionary history of a specific clade
  • Identifying defining mutations between related clades
  • Comparing multiple clades side-by-side
  • Exporting clade data for downstream analysis
  • Quickly checking the current nomenclature for a lineage

Data Source

Authoritative Nomenclature Repositories

All clade nomenclature data is sourced directly from the official Influenza Clade Nomenclature GitHub repositories, which are maintained by the Nextstrain team and international influenza surveillance networks.

The tool supports three major seasonal influenza lineages:

Lineage Repository Path
H3N2 seasonal-flu/h3n2/ha
H1N1pdm seasonal-flu/h1n1pdm/ha
B/Victoria seasonal-flu/vic/ha

Live Data Retrieval

ImportantNo Bundled Data

The Influenza Clade Explorer does not bundle or statically store clade definitions. All data is retrieved live from the official repositories each time the tool is used.

This design ensures that:

  1. Users always have access to the most current nomenclature—new clades appear as soon as they are officially designated
  2. No manual updates are required—the tool automatically reflects changes to upstream repositories
  3. Data provenance is transparent—users can verify definitions against the authoritative source

Data Processing Pipeline

When a user loads the application or switches lineages, the following pipeline executes:

fetchData(lineage) → parseData() → buildHierarchy() → renderTree()

  1. Fetch: Three TSV files are retrieved from GitHub’s raw content API:

    • clade_definitions.tsv — clade names, parent relationships, defining mutations
    • aliases.tsv — shortened alias mappings
    • representative_isolates.tsv — reference sequences for each clade

  2. Parse: D3.js parses the TSV format and merges data from all three files into unified clade objects

  3. Build Hierarchy: Parent-child relationships are resolved into a tree structure, with handling for orphaned nodes and edge cases

  4. Render: The interactive visualization is generated using D3.js with custom layout algorithms

Features

Interactive Tree Visualization

The core feature is a hierarchical tree layout that displays parent-child relationships between clades.

Feature Description
Color coding Major clade groups are distinguished by color for quick visual identification
Mutation labels Defining mutations are displayed on edges between clades
Zoom & pan Navigate large trees using mouse or trackpad gestures
Dynamic layout Adjustable spacing, node sizes, and font sizes

Node Selection and Inspection

Click any clade node to view detailed information in the Inspector Panel:

  • Full clade name and alias
  • Parent clade
  • Defining mutations (color-coded by type)
  • Representative isolate sequences

Multi-select mode: Hold Ctrl (or Cmd on Mac) while clicking to select multiple clades for side-by-side comparison.

Search and Filter

  • Real-time search: Type a clade name to highlight matching nodes in the tree
  • Descendant filter: Select a clade and filter the view to show only its descendants

Data Table View

A sortable, filterable table provides an alternative view of all clade data:

  • Sort by any column (clade, parent, mutations, etc.)
  • Filter rows in real time
  • Export to CSV for downstream analysis

Customization Controls

Fine-tune the visualization to your preferences:

Control Range Purpose
Label size 8–30px Adjust clade name text size
Edge length 40–150px Control horizontal spacing
Vertical spacing 12–150px Adjust separation between nodes
Node size 3–20px Modify circle radius
Mutation font 5–30px Change mutation label size

Manual Refresh

Click the 🔄 Refresh Data button to reload data from GitHub without refreshing the entire page—useful for checking if new clades have been added.

Usage Guide

Getting Started

  1. Open the application in your web browser
  2. Select a lineage (H3N2, H1N1pdm, or B/Victoria) from the dropdown menu
  3. Wait for data to load—the tree will render automatically once data is fetched from GitHub

Exploring the Tree

Basic navigation: - Scroll to zoom in/out - Click and drag to pan - Click a node to select it - Ctrl/Cmd + Click to multi-select

Searching for a Clade - Locate the search box above the tree visualization - Type a clade name (partial matches are supported) - Matching nodes will be highlighted in the tree - Click a search result to center the view on that clade

Comparing Clades - Click the first clade you want to compare - Hold Ctrl (Windows/Linux) or Cmd (Mac) and click additional clades - The Inspector Panel will display information for all selected clades side-by-side

Exporting Data - Switch to the Data Table view using the tab controls - Apply any desired filters or sorting - Click the Export CSV button to download the filtered data

Example Workflow: Identifying Mutations Between Clades

  • Suppose you want to identify the mutations that distinguish clade 2a.3a.1 from its parent 2a.3a:

  • Select H3N2 from the lineage dropdown

  • Use the search box to find 2a.3a.1

  • Click the node to view its details in the Inspector Panel

  • The Defining Mutations section shows the mutations that distinguish this clade from its parent

Additional Notes

Dependencies

The application is built with:

  • Quarto for document generation
  • D3.js v7 for visualization
  • Standard web technologies (HTML, CSS, JavaScript) No server-side dependencies are required—the tool runs entirely in the browser.

Limitations

  • Requires internet connection: Data is fetched live from GitHub; offline use is not supported
  • GitHub rate limits: Heavy use may encounter GitHub API rate limits (unlikely for typical usage)
  • Browser compatibility: Modern browsers (Chrome, Firefox, Safari, Edge) are recommended

Assumptions

  • Users have basic familiarity with influenza clade nomenclature concepts
  • The upstream Nextstrain repositories follow the expected TSV schema
